You can combine scroll, mousemove, and deviceorientation events to manipulate any object (Stars, Group, Camera) in a Three.js scene.

Consider performance: throttling scroll events and optimizing frame updates on mobile.

💡 Extra Ideas to Enhance the Effect
Scroll-speed dependent parallax layers: Add more Stars layers at different depths and move them at different scroll speeds.

Subtle z-axis drift: Introduce slow z axis motion on scroll for a deeper 3D effect.

Tweening / inertia: Use damping (e.g., lerp) to smooth scroll/tilt transitions.

Combine with post-processing effects like bloom or motion blur for a more cinematic background.
